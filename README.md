# DoctorBill — হাসপাতালের খরচ তুলনা

একটি উন্মুক্ত স্বাস্থ্যসেবা খরচ তুলনা প্ল্যাটফর্ম (Open Healthcare Cost Comparison Platform).

## ফিচারসমূহ
- বিভিন্ন হাসপাতালের স্বাস্থ্যসেবা ও টেস্টের খরচ তুলনা
- বিল ক্যালকুলেটর
- নিকটস্থ হাসপাতাল ও ডিরেক্টরি
- জরুরি সেবা সংক্রান্ত তথ্য
- ব্যবহারকারীদের বিল সাবমিশন ও রিভিউ

## কিভাবে রান করবেন
যে কোনো লোকাল ওয়েব সার্ভার (যেমন `npx serve web` অথবা Live Server) দিয়ে `web` ফোল্ডার রান করা যাবে।
